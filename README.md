# mipi-waveform

一条 MIPI D-PHY 数据线的多帧波形。在浏览器里滚轮自由缩放，
远看是帧的节奏，近看是方波，再近就是一个比特。

**在线看：<https://flamekm.github.io/mipi-waveform/>**

## 本地打开

零依赖、无需构建、不联网也能看。直接双击 `index.html`，或者：

```bash
python3 -m http.server 8899
```

## 页面里有什么

- 三帧 CSI-2 图像数据：帧起始短包 → 每行一个长包 → 帧结束短包 → 帧间隙
- 三个并列通道：Dp、Dn 各自 0~1.4V 量程，差分 Dp−Dn 单独 ±400mV
- 高速段是真实的 CSI-2 长包，解出数据标识、字长、包头校验、载荷、包尾校验
- 每个包内部按阶段着色：请求 → 准备 → 稳定 → 同步 → 数据 → 收尾 → 退出
- 可选一段低功耗逃逸

## 波形长度是算出来的

不是估的。改分辨率、lane 数或消隐，整条线的长度立刻跟着变：

```
每行字节      = ceil(宽 × bit每像素 / 8) + 6
每 lane 字节  = ceil(每行字节 / lane 数)
一行传输      = 每 lane 字节 × 8 / 比特率 + 包开销
行周期        = 一行传输 × (宽 + HBlank) / 宽
帧周期        = 行周期 × (高 + VBlank)
帧率上限      = 1 / 帧周期
```

比特率 = 时钟 lane 频率 × 2（DDR）。算出来的是链路一刻不停时的**上限帧率**，
真实配置会留两到三倍余量，所以同样的分辨率，实际帧率通常比这个数字低不少。

CSI-2 里没有"消隐波形"：并行 DPI 在消隐期有专门的电平，而 CSI-2 是包协议，
消隐期就是链路挂在 LP-11 上干等。所以 HBlank / VBlank 在这页里唯一的效果是把空白段拉宽。

可调：分辨率、数据格式、lane 数、时钟 lane 频率、HBlank、VBlank、帧数。

## 操作

| 动作 | 效果 |
| --- | --- |
| 滚轮 | 以光标为中心缩放 |
| 拖拽 | 平移 |
| 双击 | 复位视图 |
| Shift + 拖拽 | 量任意两点的间隔 |

键盘也能用：`←` `→` 平移，`+` `-` 缩放，`0` 复位。

## 说明

时序下限取自 D-PHY 1.x 的公开数值，不同版本和不同厂商会在此基础上加码，
实际配参请以手上芯片的收发器手册为准。

页面里的电平是理想化画法，省掉了上升下降时间、过冲和抖动。
帧间隙长度不是协议规定的数，是按帧数据时长乘系数估出来的，只影响观感。

## 文件

```
index.html          页面结构、讲解卡片、参数面板
styles.css          浅色讲义风样式
js/model.js         配置推导、时间线建模、帧/包/比特与读数文案
js/render.js        Canvas 绘制：三通道、色带、字段条、缩略图
js/interaction.js   滚轮缩放、拖拽平移、双光标测量
js/main.js          装配与调度
```

四个 js 文件用传统 `<script>` 标签按顺序加载，挂在一个 `window.MIPI` 命名空间下，
为的是 `file://` 双击就能打开，不用起服务。

1080p 一帧就有上千个行包，全量比特存数组会吃掉上百 MB。所以图像载荷不落地：
恒定段只记电平和位数，包头包尾预生成，载荷用确定性哈希按需算。
