# mipi-waveform

一条 MIPI D-PHY 数据线的多帧波形。在浏览器里滚轮自由缩放，
远看是帧的节奏，近看是方波，再近就是一个比特。

**在线看：<https://flamekm.github.io/mipi-waveform/>**

## 本地打开

零依赖、无需构建、不联网也能看。直接双击 `index.html`，或者：

```bash
python3 -m http.server 8899
```

## 页面里有什么

- 三帧 CSI-2 图像数据：帧起始短包 → 每行一个长包 → 帧结束短包 → 帧间隙
- 三个并列通道：Dp、Dn 各自 0~1.4V 量程，差分 Dp−Dn 单独 ±400mV
- 高速段是真实的 CSI-2 长包，解出数据标识、字长、包头校验、载荷、包尾校验
- 可调速率、帧数、每帧行数、每行字节、帧间隙，另有一段可选的低功耗逃逸
- 每个包内部按阶段着色：请求 → 准备 → 稳定 → 同步 → 数据 → 收尾 → 退出

## 操作

| 动作 | 效果 |
| --- | --- |
| 滚轮 | 以光标为中心缩放 |
| 拖拽 | 平移 |
| 双击 | 复位视图 |
| Shift + 拖拽 | 量任意两点的间隔 |

键盘也能用：`←` `→` 平移，`+` `-` 缩放，`0` 复位。

## 说明

时序下限取自 D-PHY 1.x 的公开数值，不同版本和不同厂商会在此基础上加码，
实际配参请以手上芯片的收发器手册为准。

页面里的电平是理想化画法，省掉了上升下降时间、过冲和抖动。
帧间隙长度不是协议规定的数，是按帧数据时长乘系数估出来的，只影响观感。

## 文件

```
index.html          页面结构、讲解卡片、参数面板
styles.css          浅色讲义风样式
js/model.js         时间线建模，帧/包/比特与读数文案
js/render.js        Canvas 绘制：三通道、色带、字段条、缩略图
js/interaction.js   滚轮缩放、拖拽平移、双光标测量
js/main.js          装配与调度
```

四个 js 文件用传统 `<script>` 标签按顺序加载，挂在一个 `window.MIPI` 命名空间下，
为的是 `file://` 双击就能打开，不用起服务。
